# Notation without musical mutation

## Context
Consume the already applied product semantics. Existing v1 songs retain canonical spelled roots and major/minor qualities; richer events and arrangements arrive through their existing delivery children.

## Decisions
A pure shared formatter maps A–G to La/Si/Do/Re/Mi/Fa/Sol while retaining accidentals and octave. Chord suffixes/slash spellings stay musical data; dual mode formats both complete symbols with an explicit primary. Shared React context supplies the current preference without feature dependency cycles. Settings own preference interaction; musical domain code never parses localized display labels.

Anonymous choice uses its own local preference key and never changes a library revision. Authenticated choice loads only the current principal's server record, defaults to Anglo-American when absent and ignores anonymous preference unless explicitly selected. Typed application handlers admit only the finite mode/primary combinations; a separate PostgreSQL preference revision and stable-command receipt commit together. Expected revisions reject concurrent stale preference writes. No caller-supplied principal or song mutation is admitted. Presentation selection is allowed during performance.

The selected display updates immediately and stays marked pending until acknowledged. Failure retains the previous server revision and reports an unsaved preference; retry uses the same command identity. Lock/user switch unmounts the feature and clears principal query state. Current-format UI tests compare complete stored libraries before/after switching; they do not claim the richer SB-NOTATION arrangement fixture has executed.
