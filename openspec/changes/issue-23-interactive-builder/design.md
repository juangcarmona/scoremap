# Exact performed editing within identified song context

Reuse the existing white/black geometry with separate exact-pitch state and theoretical markers. Two/three-octave views scroll within a bounded container; changing view never changes content. Derive each selected pitch's octave from its preserved spelling and absolute pitch. Local interaction drafts are separate from acknowledged song data; apply uses one guarded complete command and retains existing note identities/timing when editing. Cancel creates no revision. Undo requires an unchanged current edited scope and produces a normal guarded revision. Incompatible tones require explicit custom reconciliation. Detection is an explicit proposal; selecting it is a separate harmonic command.

Reusable presets contain a name, harmonic identity and exact spelled pitches. They are independent anonymous/principal resources with conditional revisions and retry receipts; song sharing cannot grant access to another principal's presets. Apply copies selected content with version/name provenance and new note identities into the selected arrangement/part. Later preset changes/deletion cannot alter copied song music. Anonymous resources never transfer on login.

Keep existing v1 editing and the explicit upgrade path. The richer builder becomes reachable only for identified events. Physical binding/range and independently selected arrangements remain subject to the complete graph invariant. Multi-device configuration views belong to #24.
