## Why

Android renders the unconfigured Material palette and a single long form. Issue #133 requires the installed Lighthouse visual system and ScoreMap's music-first direction to reach the actual native application.

## What Changes

- Map Lighthouse semantic roles into a shared Compose theme with light/dark/system behavior.
- Separate the library, song workspace and protected song sheet; adapt composition to compact and expanded widths.
- Retain musical identity, local durable acknowledgement, edit guards and native navigation.
- Publish native rendered evidence for phone/tablet, appearance and enlarged text.

## Impact

Android presentation only. No schema migration or canonical ProductShape model edit. Existing native product requirements and domain commands remain authoritative.
