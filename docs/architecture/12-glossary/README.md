# 12. Glossary

| Term | Meaning in this architecture |
| --- | --- |
| Domain command | Pure transformation of validated library data |
| Storage adapter | Existing anonymous browser IndexedDB or authorized private PostgreSQL boundary; planned native local boundary is owned by the [Android target](../05-building-block-view/android-target.md) |
| App shell | In the browser realization, cacheable assets sufficient to start offline |
| Candidate | In-memory result awaiting durable acknowledgement |
| Origin | Scheme, hostname and port owning browser storage |

Product vocabulary lives in ProductShape domain terms. This section defines technical terms only.
