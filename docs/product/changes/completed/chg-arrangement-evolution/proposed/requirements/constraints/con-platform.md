## Constraint

Retain an installable web application for landscape touch tablets, phones and desktop, delivered over protected HTTPS in deployment. Anonymous installed content supports offline editing/consultation. Authenticated offline access requires proven protected retention, scoped authorization lease and safe session recovery; persistent private offline access is disabled for the first connected local checkpoint.

Development and Production are explicit environments, not machine locations. Production refuses development identities/seeds, development serving and ephemeral persistence fallbacks. Public examples and evidence contain synthetic data only; real configuration, credentials, identities, personal music and deployment inventory remain private. Application, site, documentation and evidence origins remain parameterized pending the owner's publication choice.

## Rationale

Maintain the tablet-first product while making private recovery honest and reproducible.

## Consequences

A running development graph or local qualification is not production qualification or deployment. Shell availability does not authorize cached private content.
