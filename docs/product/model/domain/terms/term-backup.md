## Definition

A versioned complete portable export of its declared authorized musical scope, including every supported musical field and required attachment byte/association. Explicit owned preferences/resources are included only in transfer contexts permitting them. Credentials, sessions, reusable access material and authority-conferring grants are excluded.

## Distinguish From

A service volume is not a backup; an export does not prove remote save. Operator disaster recovery and musician portable exports have distinct retention/restore responsibilities. A native selected-song/ordered-set file carries current acknowledged musical content and source provenance, not the device's private revision history, app preferences or actual hardware configuration/authority.

## Usage

Anonymous browser import is explicit confirmed complete replacement. Private-service claim/import previews a bounded authorized operation and never derives permission from imported values. Native import always creates independent editable copies through consistent identity remapping and preserves every existing destination item; same-command retry is idempotent and a new deliberate import may create another copy. Unsupported/incomplete content refuses before activation. Required native owned PDF bytes travel with integrity references rather than broken device-local paths; external links remain links.
